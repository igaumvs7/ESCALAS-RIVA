AGENDA RIVA VENDAS

Sistema completo de gestão de atividades, eventos, ações e controle de verba, desenvolvido exclusivamente para o Diretor da Riva Vendas, Humberto Maciel Alves.

Desenvolvido por Igor Vivas
Visão Geral do Sistema ▾

A Agenda Riva Vendas é um sistema completo de gerenciamento de atividades para o Diretor Humberto e sua equipe. Tudo funciona direto no navegador, sem instalação.

O sistema tem 5 abas principais

  • Calendário — visualize e crie eventos por dia, semana ou mês
  • Painel — perfil, verba, estatísticas e gestão da equipe
  • Caderno — anotações ricas com folhas, post-its e exportação PDF
  • Histórico — todos os gastos registrados com exportação de relatório
  • Informações — esta tela com tutoriais completos

Dados sempre salvos

  • Tudo é salvo automaticamente no navegador (localStorage)
  • Use Exportar JSON para backup e Gerar HTML para compartilhar
  • A bolinha R no canto inferior esquerdo aparece em todas as abas com lembretes do dia
Calendário ▾

Navegação

  • Use as setas ‹ › para trocar de mês, ou clique em um mini-mês na lateral esquerda
  • Clique no título do mês (ex: ABRIL 2026) para abrir o seletor rápido de mês e ano
  • Alterne entre Mensal e Semanal no canto superior direito do calendário
  • Na visão semanal, são exibidos os 7 dias a partir de hoje

Criar evento

  • Clique em qualquer dia no calendário para abrir o painel de eventos daquele dia
  • Clique em + Adicionar data para escolher um dia via mini-calendário
  • Preencha título, tipo, responsável, valor (se houver) e clique em Salvar

Feriados

  • Dentro do painel de evento, ative o toggle "Marcar como Feriado" e informe o nome
  • O dia ficará com fundo avermelhado no calendário
Painel ▾

Perfil

  • Clique no avatar ou no ícone de perfil no topo para ir ao Painel
  • Edite nome, cargo e foto de perfil a qualquer momento

Verba

  • Defina a verba mensal clicando no botão de edição ao lado do valor
  • O sistema calcula automaticamente o que foi gasto e o que resta
  • O mostra o saldo acumulado entre meses
  • Clique no para borrar todos os valores (privacidade em reuniões)

Equipe

  • Adicione membros com nome e cargo
  • Os balões ao lado de cada membro mostram quantas ações foram atribuídas a ele
Caderno — Guia Completo ▾

O Caderno é seu espaço de anotações pessoais. Cada data pode ter várias folhas, cada uma com um editor rico completo.

1. Criar nota e folhas

Clique em Nova nota para criar uma folha no dia de hoje. Use + Nova folha na barra de páginas para adicionar mais folhas ao mesmo dia. Navegue com as setas ◀ ▶.

2. Formatar texto

Selecione o texto e clique nos botões da toolbar: B Negrito, I Itálico, U Sublinhado, S Tachado. Use o seletor Estilo para Título grande, Título médio ou Corpo.

3. Marca-texto e cor

Selecione o texto, clique no ícone marcador (marca-texto) ou A (cor do texto) e escolha a cor. Funciona como o Word: cada trecho pode ter uma cor diferente na mesma linha.

5. Listas e Checklist

  • Lista com marcador — bullets simples
  • Lista numerada — itens em ordem
  • Checklist — caixinhas de marcar; ao marcar, o item é riscado
  • ⇤ ⇥ — botões de recuo criam hierarquia

6. Post-it

Clique em Post-it na toolbar e escolha a cor. O post-it aparece na parte inferior da página. Cada post-it tem:

  • Ocultar conteúdo com blur
  • Trocar cor
  • Minimizar (deixa só o título)
  • Excluir

7. Exportar PDF do Caderno

Clique em Exportar PDF na barra do Caderno. Um painel abre listando todas as suas notas salvas. Marque quais quer incluir (ou clique em Todas), depois clique em Gerar PDF.

O PDF é aberto em uma nova aba com layout profissional Riva — todas as folhas, todas as cores e post-its (minimizados aparecem só com o título).

8. Salvamento automático

Tudo é salvo automaticamente a cada 5 segundos quando há mudanças. O indicador Salvo ✓ aparece brevemente no topo do editor. Não é necessário clicar em nenhum botão.

Histórico de Gastos ▾

O que aparece aqui

  • Todos os eventos que tiveram um valor (R$) registrado
  • Resumo: Total gasto, número de eventos e maior gasto do período

Filtros

  • Filtre por mês/ano ou use a busca por texto
  • Escolha mostrar todos os tipos ou apenas reunião, ação, etc.

Exportar Relatório

  • Clique em Exportar Relatório para abrir o painel de exportação
  • Escolha quais seções incluir: Calendário, Painel e/ou Histórico
  • Escolha a orientação: Retrato (A4 vertical) ou Paisagem (A4 horizontal)
  • Clique em Imprimir / PDF — o diálogo de impressão abre; selecione Salvar como PDF
Balão R de Lembretes ▾

A bolinha R no canto inferior esquerdo aparece em todas as abas do sistema.

  • Clique para abrir o balão com os eventos de hoje
  • A cada 20 minutos ele abre automaticamente lembrando os compromissos do dia
  • O número no canto superior da bolinha indica quantos eventos existem hoje
  • Clique em OK, entendi para fechar até o próximo lembrete
Botões do Topo — Exportar, Importar e Gerar HTML ▾

No canto superior direito existem três botões essenciais:

Exportar Dados JSON

Salva todas as informações em um arquivo .json — backup completo de eventos, verba, caderno, perfil e equipe.

  • Use antes de fechar o navegador para não perder nada
  • O arquivo pode ser importado em qualquer dispositivo
  • Ideal para backups periódicos
Importar Dados JSON

Carrega um .json salvo anteriormente, restaurando todos os dados no sistema.

  • Selecione o arquivo .json exportado antes
  • O sistema substitui os dados atuais pelos importados
  • Útil para continuar o trabalho em outro computador
Gerar HTML Compartilhar

Cria um arquivo .html com todos os dados embutidos. Diferente do JSON, o HTML gerado é o sistema completo pronto para abrir no navegador.

  • Envie por WhatsApp, e-mail ou pendrive
  • Ao abrir, o destinatário vê tudo exatamente como você deixou
  • Não precisa instalar nada
Dica: Use Exportar JSON para backup pessoal e Gerar HTML para compartilhar ou apresentar.
